## О проекте

VPN Bootstrap автоматизирует подготовку Ubuntu VPS для VPN на базе **Xray и панели 3x-ui**. Панель и подписки работают по HTTPS с сертификатом для публичного IP — собственный домен не требуется.

Проект рассчитан на новые серверы с **Ubuntu 22.04 / 24.04**, архитектурой **amd64 / arm64**, systemd и доступом root. Установка выполняется непосредственно на сервер, без Docker, с базой SQLite.

## ⚙️ setup-vpn.sh — установка

Подготавливает сервер и разворачивает основу для работы VPN:

- Устанавливает зависимости, **3x-ui** и **Xray**.
- Создаёт входящее подключение **VLESS + TCP/RAW + Reality**.
- Генерирует ключи и отдельные данные входа в панель.
- Настраивает **HTTPS панели и подписок по IP**.
- Получает сертификат и настраивает автоматическое продление.
- Настраивает **UFW**, сохраняя доступ по действующему SSH-порту.
- Проверяет службы, сертификат и итоговую конфигурацию.
- Сохраняет состояние для продолжения прерванной установки и поддерживает повторную диагностику.

Версии 3x-ui и acme.sh зафиксированы, скачиваемые файлы проверяются по SHA256. Настройки SSH сохраняются; полное обновление ОС и перезагрузка сервера не выполняются.

## 🧹 remove-vpn.sh — очистка

Удаляет установку, созданную установщиком, в том числе незавершённую:

- Останавливает службы панели и продления сертификатов.
- Удаляет файлы 3x-ui, базу данных, клиентов, ключи и сертификаты.
- Удаляет служебные файлы и сохранённое состояние установщика.
- Очищает правила UFW, добавленные установщиком; отдельный режим позволяет полностью сбросить UFW.
- Поддерживает предварительный просмотр действий без изменений на сервере.

**Данные VPN удаляются без резервной копии.** Системные пакеты, настройки SSH и файлы репозитория сохраняются. Скрипт очищает установку VPN, но не восстанавливает исходный образ Ubuntu.

## 🌐 Несколько серверов и HAPP

Подготовленные серверы можно объединить через **«Узлы» в 3x-ui** и управлять ими из одной главной панели. Пользователь получает одну подписку со списком доступных серверов в **HAPP**.

На каждом VPS работает своя 3x-ui с Xray. Подключение узлов, создание пользователей и выдача подписок выполняются в панели отдельно от скриптов. VPN-трафик идёт напрямую на выбранный сервер.
